# Tutorials

Tutorials are guided learning journeys that produce a working outcome. They
will cover, in order:

1. Run a local Mother and inspect status.
2. Package, verify, approve, and assign a minimal Child.
3. Issue a narrow ToyGrant and observe an authorized effect.
4. Diagnose a denied effect from the observation ledger.
5. Admit a peer Mother and perform a bounded call.

Until these journeys are verified end to end against the distributed release,
use [Getting started](../getting-started/index.md) for the proven installation
path. Planned tutorial titles are not claims that their procedures have been
validated.
