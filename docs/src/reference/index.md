# Reference

Reference documentation describes exact supported surfaces:

- CLI commands and options
- Configuration keys and defaults
- Child package format
- WIT contracts
- Peer protocol envelopes
- Observation records
- Release archive layout and sidecars
- Rust crates and public APIs

Implementation-owned references should be generated and checked for drift.
Rust API documentation is published under `/api/`; this book provides the
cross-crate and operator-facing reference.
