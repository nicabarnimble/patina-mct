# How-to guides

How-to guides answer focused operational questions without introducing the
whole system. The initial guide set will include:

- Verify and inspect a release archive.
- Stage a Child artifact without granting authority.
- Approve an exact artifact digest.
- Assign a Child to a scope.
- Authorize, inspect, revoke, and expire a ToyGrant.
- Read and validate the observation ledger.
- Diagnose control-plane, runtime, and peer denials.
- Upgrade and perform explicit rollback.

Commands will be copied from generated CLI reference or tested examples rather
than maintained as unverified prose snippets.
